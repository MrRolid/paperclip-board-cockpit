# Board Cockpit v0.9.4

v0.9.4 adds source-level provenance to the read-only LLM advisor.

## What changed

- Sanitized snapshot fragments now receive stable source IDs generated by Board Cockpit, not by the model.
- Issue descriptions/titles/state, recent comments, structured completion-handoff fields, project origin and owner goals can be cited directly.
- The advisor receives a compact allow-list of valid source IDs and explicit citation rules.
- Advisor output is audited for unknown citations and selected factual-looking lines without citations.
- `#state` is the only source class treated as independently established host state; comment/description/handoff citations remain reports.
- Citation links in the UI open the relevant issue and expose the sanitized source excerpt in a tooltip.
- The security panel can expand both provenance findings and the exact paths/excerpts changed by input sanitization.

## Security boundary

Provenance is attached only after untrusted input sanitization. Text copied into a comment cannot create a registry entry merely by containing a citation-looking marker. Unknown citations are surfaced as warnings; the audit does not rewrite, block or execute model output.

## What did not change

- No Paperclip business-data write capabilities were added.
- Deterministic project-state, continuation, wave-resolution and blocker logic are unchanged.
- The direct LLM HTTP destination policy from v0.9.3 is unchanged.
- Artifact/document ingestion remains out of scope.
- Multilingual prompt-injection pattern expansion remains planned for v0.9.5.
